# Support

This page routes questions, bug reports, and security reports for Workshop.
Read it when you need help choosing the right public channel.

Use GitHub Issues for reproducible bugs and feature requests. Use the issue
forms so maintainers receive the environment, expected behavior, and scope
needed to triage a report. For a suspected vulnerability, follow
[SECURITY.md](SECURITY.md) rather than creating a public issue.

Pull requests follow the process in [CONTRIBUTING.md](CONTRIBUTING.md).
